## 二、口径

- 检索 4 个标题关键词：实施退市风险警示 / 实施其他风险警示 / 撤销退市风险警示 / 撤销其他风险警示。
- 标题过滤剔除：申请、律师、问询、回复、进展、提示、继续被实施、部分撤销、撤销部分、事先告知、**存在被实施 / 可能被实施 / 将被实施 / 风险提示**（最后一组是业绩预告里的“可能被 ST”，不是真实施）。
- 去重：同一 (代码, 类型) 90 天内只留最早一条；跨 90 天视为两次事件。
- 日期精度：公告时间是日级（00:00 UTC → 北京时间 08:00），只能当日 08:00 可见。

## 三、已知偏差（写进预注册前必须处理）

1. **只有标题，没读 PDF 正文**：事由（资金占用/违规担保/内控否定/财务）拿不到，第一版只能按“类型”分层，不能按“假 ST”分层。
2. **40 条“撤销退市但继续其他风险”**：不是干净摘帽，已单列，不并入 `rem_delist`。
3. **T+1 可成交率未测**：需要逐事件连行情，看 T+1 是否一字/停牌。这是下一关（门槛 ≥60%）。
4. **行情覆盖**：2016–2020 的长历史日线本地没有；`product-data-c1` 缓存覆盖 2021–2026，腾讯 640 天、新浪 1500 天也只够近 2–6 年。首版建议只做 **2021–2026（约 1,260 个事件）**，2016–2020 标“待补行情”。
5. **退市样本**：走完退市流程的公司在东财/腾讯的当前接口里没有行情。实施腿的分母必须包含这些，否则幸存者偏差；第一版先做**撤销腿**（撤销时公司必然还在交易），实施腿等退市库。
6. **2021 年是异常年**（333 件，退市新规首年），分年必须拆开报，不能合并成一个均值。
